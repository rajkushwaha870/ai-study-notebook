 Study AI Notebook

An AI-powered study platform built with Astro, React, Supabase and Cloudflare.

Features
- Google Login
- AI Chat
- Notes Management
- PDF Viewer
- Image OCR
- PWA Support

Live Demo
https://note-book.growhigh990.workers.dev

 Tech Stack
- Astro
- React
- TypeScript
- Supabase
- Cloudflare Workers
- Tailwind CSS

 Installation
npm install
npm run dev
